# 🍥 Naruto Guess Who — Character Images & Photopea Template

A fan-made **Naruto-themed character set** for the 3D-printed Guess Who board, together with a reusable **Photopea template** for creating your own custom sets.

This repository contains:

* **96 Naruto character images**, organized into 4 sets
* Printable sheets containing the character sets
* A **Photopea `.psd` template** for creating your own character images
* Everything needed to prepare the character artwork for the 3D-printed game board

## 🎲 About

The physical Guess Who board is the **[Guessing Game Board + Frames](https://makerworld.com/en/models/15784-guessing-game-board-frames)** model by **matthiasdeblaiser** on MakerWorld.

This repository provides the character artwork designed to fit the frames of that board.

A single game board contains **24 character frames**.

Each printable sheet contains **48 characters**, which corresponds to **two complete 24-character sets**.

```text
Sheet 1
├── Set 1 → 24 characters
└── Set 2 → 24 characters

Sheet 2
├── Set 3 → 24 characters
└── Set 4 → 24 characters
```

This gives a total of:

**4 sets × 24 characters = 96 character images**

## 🧩 How the Sets Work

Each board uses **24 characters**.

A normal game uses **two boards**, so both players need their own copy of the character set.

The printable sheets are therefore designed to be **printed twice**.


### Printing Summary

| Item                              | Quantity |
| --------------------------------- | -------: |
| Printable sheets                  |        2 |
| Characters per sheet              |       48 |
| Sets per sheet                    |        2 |
| Characters per set                |       24 |
| Sets in total                     |        4 |
| Character images in source sheets |       96 |
| Sheets to print for 2 boards      |    **4** |
| Printed character cards           |  **192** |

> **Important:** For a normal two-board game, print **each sheet twice**.

This provides both boards with the complete 24-character set they need.

## 🎨 The Photopea Template

The character artwork in this repository was created using **[Photopea](https://www.photopea.com/)**.

The template is provided as a `.psd` file, so it can be opened and edited directly in Photopea.

**You do not need Adobe Photoshop to use the template.**

Photopea runs in a web browser and supports PSD files, making it possible to customize the character artwork without purchasing Photoshop.

### 🌍 Not Just for Naruto

### Creating Your Own Theme

1. Open the `.psd` template in **Photopea**.
2. Replace the character artwork.
3. Adjust the character's position and crop.
4. Keep the artwork inside the intended image area.
5. Export the character image.
6. Repeat for your desired characters.
7. Arrange the characters into 24-character sets.
8. Create your printable sheets.
9. Print the sheets twice for a standard two-board game.

This makes the template useful as a **general-purpose custom Guess Who character template**, not just a Naruto resource.

## 🖼️ Character Images

The character images are prepared specifically for the physical frames of the 3D-printed board.

Target image size:

**24.5 × 39 mm**

For best results:

* Print at the intended scale.
* Do not stretch or distort the images.
* Keep faces and important details inside the safe area.
* Use consistent positioning and cropping.
* Check the final dimensions before cutting.
* Test one character before printing the complete set.

## 🛠️ Using the Template

The template is designed to make it easy to maintain a consistent appearance across a complete character set.

It can be used to:

* Create new character images
* Replace existing characters
* Create completely new themes
* Adjust cropping and positioning
* Maintain consistent image dimensions
* Export print-ready artwork
* Build additional 24-character sets

### Creating a New Character

1. Open the `.psd` template in Photopea.
2. Replace the character artwork.
3. Adjust the position and crop.
4. Make sure the character fits correctly within the frame.
5. Export the character image.
6. Add it to the appropriate set.


## 🖨️ Printing

Print the sheets at **100% / actual size**.

Avoid printer options such as:

* Fit to page
* Scale to fit
* Shrink oversized pages

unless required by your printing workflow.

For a standard two-board game:

**Print `sheet-01` twice and `sheet-02` twice.**

After printing:

1. Cut out the character images.
2. Check that they are approximately **24.5 × 39 mm**.
3. Insert them into the 3D-printed frames.
4. Repeat for all four sets.
